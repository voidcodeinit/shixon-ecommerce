# Shixon E-commerce

A Persian RTL e-commerce storefront interface built with HTML, CSS, and Bootstrap RTL. The project focuses on recreating the structure of a realistic online fashion store, including navigation, promotional banners, product listings, news content, customer guidance, and a detailed footer.

## Features

- Persian RTL layout
- Responsive Bootstrap grid
- Multi-level storefront navigation
- Promotional slider/banner area
- Product listing sections
- News and campaign sections
- Customer guidance and store information sections
- Bootstrap tooltips
- Custom Iran Sans font
- Font Awesome icons
- Responsive footer and trust elements
